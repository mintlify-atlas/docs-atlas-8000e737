CodeLoom Engine is a headless backend for AI-powered coding agents. It binds to a workspace directory, exposes a newline-delimited JSON (NDJSON) protocol over a Unix domain socket, and lets any client — a TUI, a web app, an editor plugin, or a test harness — drive a full LLM orchestrator without importing a single line of agent internals. The orchestrator spawns named personalities that share 64 tools for reading, searching, understanding, and editing code.

## What the engine does

The engine enforces a hard boundary between clients and agent internals. Clients speak JSON over a socket; they never touch the orchestrator, tool registry, or LLM client directly. Every message crossing the socket is a typed dataclass with a `type` field.

## Quick look

Start the engine pointed at a workspace, then send JSON commands over the socket:

```bash
# Start the engine
python app.py /path/to/your/project

# From another terminal, connect with the reference TUI client
python dummy_client.py /path/to/your/project
```

Once connected, any `SubmitUserMessage` command kicks off the full orchestration loop — the engine picks tools, spawns subagents, edits files, and streams back events as NDJSON lines.

<Note>
  The engine requires Python 3.9+, an OpenRouter API key, and `ripgrep` (`rg`) on your PATH. LSP features additionally need the language server for your project (pyright, typescript-language-server, or gopls).
</Note>
